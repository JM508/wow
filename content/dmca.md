本站尊重知识产权，也尊重原创。**最近更新：2026 年 10 月 17 日。**

## 一、素材来源

1. 本站游戏代码在 GitHub 公开开源（[JM508/wow](https://github.com/JM508/wow)），许可见仓库内标注。
2. 页面文案、图标、布局为站长原创或基于开源主题（Hugo PaperMod，MIT 许可）定制。
3. 游戏内皮肤图片来自站长自制或已获权利人授权使用的素材；如你对某素材的权利归属有异议，欢迎按下方流程反馈，我们会在核实前先行下架争议素材。

## 二、投诉（通知-删除）

若你是权利人或其授权代理人，认为本站内容侵犯了你的合法权益，请通过 GitHub Issues 提交投诉：

**投诉入口**：[JM508/wow · Issues](https://github.com/JM508/wow/issues)（标题请注明「版权投诉」）

投诉材料应包含：

1. 被投诉内容的**具体页面地址**（URL）与涉及素材的描述或截图；
2. 你对涉嫌侵权作品享有权利的证明（原创说明、首发链接、登记证书等任一）；
3. 你的联系方式（可用于核验身份的账号或邮箱）；
4. 声明：**「本人善意相信所投诉的使用方式未经权利人授权，且本投诉信息属实，如有不实愿承担法律责任。」**

## 三、处理流程与时限

1. 收到完整投诉材料后，一般 **7 个工作日**内回复处理结果；
2. 材料不全的，会一次性告知需补充的内容；
3. 投诉成立的，立即删除或下架相关内容，并视情况在页面保留处理说明；
4. 恶意投诉、虚构权利的，本站保留追究责任的权利。

## 四、反通知

被投诉方若认为内容不构成侵权，可提交反向通知（含相同要素的声明与证明）。收到有效反通知后，本站会将材料转告投诉方；除非投诉方在合理期限内证明已提起法律程序，被下架内容可恢复。
